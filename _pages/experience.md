<section class="entry" id="itas"><h3>软件工程课程项目：智能文本标注系统 ITAS</h3><div class="meta">2024.03–2025.01 · 产品经理、软件开发</div><ul class="project-points"><li>负责需求分析、产品规划与系统实现。ITAS 是面向科研文献的多领域智能文本标注与信息抽取系统。</li><li>支持 PDF 批量上传、段落与实体标注、审核、模型导出，并通过大语言模型与 few-shot 学习提取预设信息。</li><li>构建 BM25 + RAG few-shot 抽取流程，输出前驱体、用量和合成条件的结构化 JSON；三个 MOF 数据集 macro-F1 达 0.94，zero-shot 达 0.77。</li></ul></section>

<section class="entry" id="materagent"><h3>MaterAgent · 面向材料研发全流程的 Agent Harness</h3><div class="meta">2026.01–至今 · 架构设计、软件开发</div><ul class="project-points"><li>参与新材智脑的产学研合作项目，推动智能体运行支撑框架与配套工具在材料研发流程中的落地应用。深入理解 PI-Agent 框架与核心技术，梳理 agent loop、runtime、plugin 和智能体生命周期，参与材料研发全流程 Agent Harness 架构设计。</li><li>设计并开发 Paper Browser MCP 与 Database MCP：Paper Browser 支持按 DOI、标题或正文检索论文，并读取论文或章节中的段落、表格等证据；Database MCP 面向材料研发数据库提供结构化查询与 BM25、dense 双路检索，返回排序记录、检索分数和元数据。</li><li>构建覆盖 10 个任务共 140 题的材料 QA benchmark，涵盖单条查询、条件筛选与排序、工艺归纳、论文取证和机理分析。</li></ul></section>
